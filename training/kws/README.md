# Модель ключевых слов колонки (вейк + команды без облака)

Шифу 07.11: свой споттер вместо облачного распознавания каждого шума; учится на песочнице (GPU), переучивается на другие слова.

**Переучить на другие слова** — поправь `classes` (и `negatives`) в `config.yaml`, потом на песочнице:

```bash
ssh ros2@10.1.1.250 'cd ~/kws && nohup ./run.sh > out/run.log 2>&1 &'
ssh ros2@10.1.1.250 'tail -5 ~/kws/out/train.log'
```

Что делает `run.sh`: venv (torch CUDA) → `synth.py` (озвучка новых фраз голосами Silero, офлайн) → `train.py` (DS-CNN на
log-mel 40, 16 кГц, окно 1 с; шум, эхо, скорость — на лету) → `out/`: `model.onnx`, `kws.npz` (веса + банк mel-фильтров),
`meta.json`, `report.txt` (точность на голосе, которого не было в обучении, и ложные срабатывания).

**Живые примеры** копит сама колонка (`station_host.py`, `kws_collect`): первая секунда обращения с вейком → вейк, секунда
фразы без вейка → «чужое». Забрать на песочницу (с ПК): `training/kws/pull_real.sh`. Фон мастерской — `data/noise/*.wav`.
