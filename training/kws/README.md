# Модель ключевых слов колонки (вейк + команды без облака)

Шифу 07.11: свой споттер вместо облачного распознавания каждого шума; учится на песочнице (GPU), переучивается на другие слова.

**Переучить на другие слова** — поправь `classes` (и `negatives`) в `config.yaml`, потом на песочнице:

```bash
ssh ros2@10.1.1.250 'cd ~/kws && nohup ./run.sh > out/run.log 2>&1 &'
ssh ros2@10.1.1.250 'tail -5 ~/kws/out/train.log'
```

Что делает `run.sh`: venv (torch CUDA) → `synth.py` (озвучка новых фраз голосами Silero, офлайн) → `train.py` (DS-CNN на
log-mel 40, 16 кГц, окно 1 с; шум, эхо, скорость — на лету) → `out/`: `model.onnx`, `kws.npz` (веса + банк mel-фильтров),
`meta.json`, `report.txt` (точность на голосе, которого не было в обучении, и ложные срабатывания).

**Живые примеры** копит сама колонка (`station_host.py`, `kws_collect`): первая секунда обращения с вейком → вейк, секунда
фразы без вейка → «чужое». Забрать на песочницу (с ПК): `training/kws/pull_real.sh`. Фон мастерской — `data/noise/*.wav`.

**На колонке** (07.11): `export_c.py` → `out/kws_model.bin` (60 КБ, BatchNorm слит), `build_kws.sh` → `kws_run.armv7`
(статически, NEON), класть в `/data/opt/rbx/kws/`. Фраза 2 с — 0,43 с на колонке. `check_c.py` сверяет C с PyTorch
(07.11: 19 из 19, вероятности ±0,006). Хост — **режим тени**: `🔑 kws <метка> <p>` в логе рядом с облачным STT,
решает пока облако.

Первая модель 07.11 (по 20 озвучек на фразу, 4 голоса в обучении, голос eugene — только проверка): точность 0,82,
«Игорёк» 84 %, ложный вейк на чужом 2 % (с уверенностью > 0,8 — 0,5 %). Живьём через воздух (динамик katana → колонка):
«Игорёк, который час?» → igorek 0,98; «Робот, расскажи анекдот» и 7 фраз анекдота робота → _unknown_ 0,85–1,00.

Вторая модель 07.11 (60/15 озвучек на фразу, плюс 16 живых записей колонки): точность 0,90, «Игорёк» 94 %, стоп/громче/тише
80/82/97 %; ложные с уверенностью > 0,8 — 0,62 % (без порога «чужое → Игорёк» 6,4 % — решение вейка только с порогом
0,8). C = PyTorch 20 из 20. На колонке `kws_model.bin` = v2, `kws_model_v1.bin` — запасная.
