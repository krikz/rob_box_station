# Биометрия голоса Алисы (пол, «возраст», голосовой отпечаток)

В прошивке колонки: `/system/vendor/quasar/bio_lingware` (1,5 МБ) — ECAPA-TDNN (`body.tflite` по 20 кадров
`[1,20,80]`→`[1,20,128]`, `head.tflite` → отпечаток 512), линейные `gender_classifier` (порог 0,55, выход — вероятность
«женщина») и `age_classifier` (порог 0,6; по форме — «ребёнок/взрослый», **догадка**). Признаки — Kaldi log-fbank 80,
кадр 40 мс, шаг 24 мс, предыскажение 0,97, Хэмминг (`features_config.json`). Операции — **только стандартные** TFLite.

Проверка 07.11 (`feats.py` на katana — Silero + torchaudio; `run.py` в WSL — `tflite_runtime`, numpy 1.x):

| голос | пол | «возраст» |
|---|---|---|
| Silero aidar / eugene (м) | 0,028 / 0,125 | 0,045 / 0,062 |
| Silero baya / kseniya / xenia (ж) | 0,888 / 0,854 / 0,767 | 0,183 / 0,137 / 0,041 |
| записи колонки 1,2 с (Шифу, мастерская) | 0,05–0,44 (одна 0,78) | 0,001–0,27 |

Отпечаток: одного пола голоса Silero похожи на 0,71–0,76, разного — −0,01…0,28. Детских голосов не было.
На колонке своя `libtflite.so` падает при создании интерпретатора — нужен свой рантайм TFLite под armv7.
